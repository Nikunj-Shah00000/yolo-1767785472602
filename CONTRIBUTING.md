# Contributing to YOLO Project

## The YOLO Way

1. **No Pull Request Templates** - Write whatever you want
2. **No Code Reviews** - Trust yourself
3. **No Testing Required** - If it compiles, ship it
4. **No Documentation Updates** - The code is self-documenting
5. **No Approval Process** - Merge your own PRs

## How to Contribute

1. Fork the repo
2. Make changes
3. Create PR
4. Merge immediately
5. YOLO! 🚀

## Code Style

We don't have one. Write however you feel like. It's all good!

## Testing

Tests are optional. If you want to add them, cool. If not, also cool.

## Review Process

There is none. Merge and move on!
